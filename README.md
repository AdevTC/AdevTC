<details>
<summary><sub>Cómo se calculan las estadísticas</sub></summary>

Datos de la API pública de GitHub, con la fecha de consulta en cada tarjeta. Los repositorios cuentan todos los públicos propios. Stars y forks suman los repositorios propios que no son forks; los lenguajes se calculan por bytes, excluyendo forks y el perfil.

La actividad recoge commits asociados a mi usuario en las ramas por defecto de mis repositorios públicos durante los últimos 90 días, excluyendo forks y este perfil. Los días activos y la mejor racha se refieren a esa ventana. No incluye PR, issues ni actividad privada.
